# Emotional Home - 情绪疏导网站

一个纯前端的情绪疏导网站，帮助用户安全地发泄负面情绪、理清思绪，最终找回内心的平静与快乐。

🌐 **在线体验**: [https://evenshry.github.io/emotionalHome/](https://evenshry.github.io/emotionalHome/)

## 🌟 产品特色

- **零门槛使用**：无需注册登录，打开即可使用
- **隐私保护**：所有数据仅存储在用户本地浏览器中，不上传服务器
- **完整流程**：从情绪发泄 → 理性梳理 → 积极转化的完整心理疏导
- **丰富体验**：多种互动方式（文字、涂鸦、游戏、呼吸引导等）
- **数据可视化**：记录情绪变化轨迹，直观了解自己的情绪模式

## 📱 核心功能

### 情绪发泄区
- **文字倾倒**：自由输入情绪文字，支持"撕碎"动画删除
- **涂鸦画布**：自由绘画发泄，支持颜色选择和清空重画
- **虚拟压力球**：3D 弹性球体，点击时产生形变动画和计数
- **捏泡泡**：有趣的泡泡消除游戏，放松心情
- **呼吸游戏**：4-7-8 呼吸法动画引导

### 情绪梳理
- **引导式对话**：渐进式问题卡片，帮助理清情绪根源
- **情绪卡片**：选择并记录当前情绪类型，支持拖拽排序

### 积极转化
- **感恩日记**：引导写下值得感恩的事，支持本地保存
- **积极重构**：将负面想法转化为积极视角的练习
- **身体扫描**：渐进式肌肉放松引导

### 情绪仪表盘
- 情绪趋势可视化展示
- 统计疏导完成次数和连续天数
- 历史记录查看

## 🛠️ 技术栈

- **前端框架**：React 18 + TypeScript
- **构建工具**：Vite
- **路由管理**：React Router v6
- **状态管理**：Zustand
- **3D 渲染**：React Three Fiber + Cannon
- **样式方案**：Sass + CSS Modules
- **代码规范**：ESLint + Prettier + Husky

## 🚀 快速开始

### 环境要求
- Node.js >= 16
- Yarn 4.x

### 安装依赖

```bash
yarn install
```

### 启动开发服务器

```bash
yarn dev
```

### 构建生产版本

```bash
yarn build
```

### 预览构建结果

```bash
yarn preview
```

### 代码检查与格式化

```bash
# 代码检查
yarn lint

# 代码格式化
yarn format
```

## 🎨 设计理念

### 视觉风格
- **色彩主题**：温暖的日落橙到宁静蓝的渐变
- **布局**：卡片式设计，大量留白，居中对齐
- **交互**：圆润的胶囊形按钮，流畅的过渡动画
- **字体**：Nunito（标题）+ Source Sans 3（正文）

### 动效设计
- 页面淡入淡出切换
- 按钮悬浮和点击反馈
- 情绪相关的色彩渐变过渡
- 3D 弹性形变动画

## 💾 数据存储

所有数据使用浏览器 `localStorage` 本地存储，包括：
- 情绪历史记录
- 感恩日记条目
- 使用统计数据

用户可以随时清除所有本地数据。
